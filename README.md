# Night Bedroom Piano Player 🎹🌧️

A single-page classical piano music player built for the **Full Stack Developer Bootcamp for Beginners – Contest #1**.

## 🎵 Concept

- **Genre:** Classical Piano (Calm & Romantic)
- **Theme:** Night Bedroom Chill – study in a cozy bedroom while it’s raining outside
- **Goal:** Create a calm, nostalgic listening experience suitable for studying, reading, or relaxing at night.

The UI is designed to feel like a warm bedroom at night.

## 🧩 Features

- Single-page music player
- Play / Pause
- Previous / Next track
- Click on any track in the list to play it
- Auto-plays the next track when the current one finishes
- Simple, clean, mobile-friendly UI

## 🛠 Tech Stack

- **Vite + React**
- **HTML / CSS**
- No external UI libraries

## 🚀 How to Run Locally

```bash
npm install
npm run dev
```
